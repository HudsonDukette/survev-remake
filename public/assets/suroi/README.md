# Suroi environment asset pack

This folder contains a small selection of SVG environment sprites from [HasangerGames/suroi](https://github.com/HasangerGames/suroi).

- Tree foliage/trunk
- Bushes and blueberry bushes
- Five rock variants
- Barrel and regular crate
